## [0.1.0] - 2026-09-18

Premiere version du module C++ SignalisationFrancaiseRealisteMod.dll et de ses ressources. Necessite SDK 0.7.2 et Hub 0.2.3. NRF Loader charge automatiquement la DLL ; le SDK gere les commandes d affichage et de restauration des textures.

Cette version ne calcule pas encore les indications francaises et ne modifie pas automatiquement les textures sans commande. Validation : compilation et tests de chargement/ressources. La validation visuelle en jeu reste a effectuer. Activer les ressources dans le jeu pour les utiliser.
